# 中国农业大学“耘思”大思政平台 - 比赛答辩展示原型

本项目是一个专为比赛答辩展示设计的高校“大思政平台”静态网页原型。页面整体视觉风格庄重、正式、清爽，深度结合了思想政治教育的红色底蕴与中国农业大学的农业特色。

---

## 📌 项目定位与性质

1. **比赛答辩展示原型**：本项目仅用于比赛答辩与视觉框架演示。
2. **纯静态网页**：页面完全由 HTML、CSS 和少量 JavaScript 构成，**无任何后端、数据库、登录系统或第三方数据接口**。
3. **本地零依赖**：不需要配置任何本地服务器或运行环境，在任意浏览器中直接双击打开 `index.html` 即可完整渲染所有视觉效果与交互。
4. **占位与拓展性**：页面中所有图片资源、文章列表和新闻均采用高保真占位符形式。后续既可以接入真实的 API 接口，也可以通过手动填入新华社、人民网、学习强国及中国农业大学新闻网的公开内容进行补充。

---

## 🎨 视觉设计与风格说明

本项目在设计上参考了**“学习强国”**与**“人民网”**等权威学习和新闻门户的气质与信息排布逻辑，在保证自主开发、不侵犯版权的前提下，实现了以下视觉创新：

*   **配色体系**：
    *   **主红色（#B80000 / #8F0000）**：作为思政平台底色，传递权威、严肃的红色教育学习氛围。
    *   **辅助绿色（#1F7A3A）**：体现中国农业大学“强农兴农”办学特色。
    *   **底色（#FAF8F5 米白色）**：采用温润的书页白作为底色，提升长文阅读的舒适感与权威感。
    *   **点缀金色（#FFD700）**：用于高亮强调与金色线条，增加答辩展示的精细度。
*   **细节纹理与修饰**：
    *   使用纯 CSS 及内联 SVG 绘制了淡淡的**麦穗几何纹理**与**波浪线条**，用做顶部横幅及专题卡片背景，增强了页面的“中国农业大学特色”。
    *   卡片标题左侧采用**红绿双色并排的竖线**作为装饰符，直观展现了“思政（红）+ 农大（绿）”的有机结合。
*   **新闻列表排版**：
    *   重点推荐区域首条新闻采用高亮极浅红底色，并带有闪烁的金色星星 `★` 前缀。普通新闻采用小红方块 `■` 作为前缀，列表之间带有虚线分隔，层次分明。

## ⚙️ 交互功能

*   **实时动态日期**：顶部信息栏通过 JavaScript 自动获取客户端时间，显示为正式的公文日期格式（例如：`今天是：2026年5月21日 星期四`）。
*   **精美大图轮播**：首页首屏焦点图支持自动循环播放（间隔 5 秒），且鼠标移入时自动暂停播放，方便答辩时停留讲解；左右箭头和指示圆点皆可点击进行手动切图。
*   **模拟导航切换**：点击导航栏不同项目时，会通过 JavaScript 自动切换当前激活的高亮状态。
*   **卡片浮动特效**：首页卡片、专题按钮以及下方学习资源入口卡片均在 CSS 中配置了平滑的浮起与投影加深特效，增强页面的呼吸感。

## 💡 后续填充与接入建议

1. **图片替换**：
   在 `images/` 目录下放置您的图片素材，并将 `index.html` 中对应的 `image-placeholder-gradient` (如轮播图) 或 `small-image-placeholder` (如卡片小图) 替换为标准 `<img>` 标签即可。建议分辨率已在 `images/README.md` 中标明。
2. **链接接入**：
   当前页面中所有链接的 `href` 均为 `#` 占位。您可以将它们替换为如中国农业大学官网、学习强国专题等真实的外部链接，或是本站的其他二级子页面。
